# Rust Data-Oriented and Aspect-Oriented Programming

Public destination for the learner code companion to the Rust DOP/AOP course.

## Current status

The practical code release is pending review and execution qualification. This repository currently contains this entry note only. It does not yet provide an installable or tested Rust workspace.

The intended companion covers typed data and state transitions, measured data layout, explicit cross-cutting joins, API and persistence boundaries, event processing, and desktop integration. Guided exercises and reference solutions will accompany the code. Dependency locks, toolchain compatibility, and native runtime checks remain prerequisites for its practical release.

## Learner route

Use the published release instructions once the code is available: clone the repository, use its declared Rust toolchain, run the applicable workspace and integration checks, complete a starter exercise, compare the reference solution, and record the result of an extension. No compilation, benchmark, database, broker, or native UI result is claimed by this entry note.

## Content and reuse

The companion is intended for reusable code, practical instructions, and exercises. Course narration, slides, books, and videos are outside this repository. The code release will include its license and dependency attribution. No code license or third-party redistribution rights are established by this note.
